# OboDesk Problem Evidence Map

Updated: 2026-05-20

Purpose: this document records evidence about real user problems for OboDesk's evidence-based MVP stage. It is not a vision document, feature roadmap, or marketing narrative.

Current rule: every product, PDP change, content direction, Product Center field, or automation idea should be tied back to a specific target user, scenario, pain point, current alternative, and observable evidence.

## Evidence Strength / 证据强度

| Evidence strength / 证据强度 | Meaning / 含义 | Examples / 例子 |
| --- | --- | --- |
| None | No direct evidence yet. | Internal intuition, AI-generated assumptions, founder preference. |
| Weak | Indirect or anecdotal evidence only. | Competitor reviews, social comments, isolated user remarks, one-off support questions. |
| Medium | Repeated signals from relevant users or real behavior. | Multiple interviews, repeated PDP questions, add-to-cart behavior, repeated objections, supplier/product fact gaps that affect purchase confidence. |
| Strong | Repeated behavior tied to business outcomes. | Purchases, repeat purchases, referrals, low return rate, clear content-to-cart conversion, repeated channel performance. |

Weak evidence must be treated as an unvalidated hypothesis. It can justify the next small validation action, but it cannot be used as a verified fact, launch-stage signal, product expansion reason, or automation trigger.

## Current Open Questions

- Which user segment has the strongest need: home office workers, desk setup builders, creators, gamers, or technical accessory buyers?
- Does the OboDesk "desk system" framing improve purchase confidence, or do users still shop by individual product and price?
- Which product category creates the clearest initial value: monitor riser, desk mat, lighting, connectivity, or microphone?
- Which missing facts actually block purchases, and which are only internal completeness concerns?
- Do safer, more factual PDPs improve trust enough to offset less aggressive marketing claims?
