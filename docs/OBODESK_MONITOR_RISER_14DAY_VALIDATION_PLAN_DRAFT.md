# OboDesk Monitor Riser 14-Day Validation Plan Draft

Draft date: 2026-06-12

Status: Local draft only. Do not publish, import, sync, or automate from this file.

## 1. Validation Goal

For the next 14 days, OboDesk validates only one question:

Can `Signature Monitor Riser` use small-scale TikTok content tests to bring cold visitors to the Shopify PDP and produce recordable real behavior signals?

Primary signals:

- PDP view.
- Add to cart.
- Checkout started.
- Purchase.
- Revenue.
- User questions.
- User objections.
- Competitor comparisons.
- Page or trust issues.

Views alone are not validation. A TikTok post is useful only if it can be connected to shopper intent, product questions, PDP sessions, add-to-cart, checkout started, purchase, or clear objections.

## 2. 14-Day Scope Freeze Rules

Allowed during this validation window:

- Keep the existing Shopify buying path observable and manually testable.

- Summarize evidence and decide Continue / Modify / Pause.

## 5. Daily Plan

Day 1:

- Confirm this plan and the validation log template are ready.
- Manually review allowed and forbidden Monitor Riser claims.
- Prepare a cold-visitor Shopify manual test using the checklist draft.
- Do not edit Shopify or theme files.

Day 2:

- Human manually tests the live cold-visitor path: Home -> Collection -> PDP -> Add to cart -> Cart -> Checkout -> payment entry -> footer trust pages.
- Record Pass / Fail / Need Review results.
- Stop validation launch if a P0 blocker is found.

Day 3:

- Prepare 2-3 TikTok content angles using only safe facts.
- Define CTA and expected behavior for each angle.
- Review claims before filming or posting.

Day 4:

- Publish or manually run the first small content test only after human approval.
- Record Content_ID, angle, CTA, and baseline metrics.

Day 5:

- Check early signals: views, profile visits, link clicks, PDP views, add-to-cart, questions, objections.
- Do not judge by views alone.

Day 6:

- Run 2-3 task-based shopper observations.
- Ask users to find a desk setup product and explain doubts, alternatives, and purchase blockers.

Day 7:

- Weekly review 1.
- Decide whether the content angle is producing buyer-intent signals or only attention.
- Choose Continue / Modify / Pause for the next week.

Day 8:

- If continuing, refine one variable only: content angle, CTA, PDP FAQ note, or target audience.
- Do not change product scope.

Day 9:

- Run the second small content test.
- Record the same metrics as Day 4.

Day 10:

- Review user questions and objections.
- Classify them as product fact gap, trust gap, price gap, competitor gap, page issue, or no-fit audience.

Day 11:

- Conduct additional shopper observations until total observation count reaches 5-10.
- Focus on comprehension, trust, price comparison, and reason to buy from OboDesk instead of marketplace alternatives.

Day 12:

- Review Shopify analytics manually: PDP views, add-to-cart, checkout started, purchases, top exits.
- Attach screenshot or evidence link in the CSV draft if available.

Day 13:

- Summarize all signals by content angle and user segment.
- Identify whether the strongest issue is product demand, PDP trust, traffic quality, price, or missing product facts.

Day 14:

- Final 14-day decision review.
- Choose Continue / Modify / Pause.
- Decide whether Monitor Riser remains the main product, needs a messaging change, or should be paused before more work.

## 6. Continue / Modify / Pause Rules

Continue if:

- TikTok or organic content sends measurable visitors to the Monitor Riser PDP.
- At least one buyer-intent signal appears: add-to-cart, checkout started, purchase, direct buy request, repeated product-specific questions, or strong positive comparison.
- Page path remains technically healthy.
- Objections are specific enough to improve PDP, content, price framing, or FAQ.

Modify if:

- Content gets views but weak link clicks or PDP visits.
- PDP receives visits but no add-to-cart and users report unclear value, weak trust, poor images, price concerns, or missing specs.
- Users understand the product but compare unfavorably against Amazon, TikTok Shop, IKEA-style accessories, or existing monitor stands.
- Questions repeatedly point to missing material, load capacity, package, size fit, or shipping information.

Pause if:

- Live cold-visitor path has a P0 blocker.
- No meaningful buyer-intent signal appears after two content tests and 5-10 relevant observations.
- Users do not understand why to buy a Monitor Riser from OboDesk.
- Unsafe claims would be needed to make the product persuasive.
- Work starts drifting into new tools, products, theme changes, or automation.

## 8. Weekly Review Questions

- Which content angle produced PDP visits, not just views?
- Did visitors add to cart, start checkout, purchase, or ask product-specific questions?
- What did users not understand about the product?
- What objections repeated across users or comments?
- Which missing product facts blocked trust or purchase intent?
- Did users compare OboDesk against Amazon, TikTok Shop, IKEA, or existing desk accessories?
- Did the PDP communicate the value without founder explanation?
- Were any claims too vague, too cautious, or too risky?
- Did the store path create any friction from Home to Checkout?
- Should the next step Continue, Modify, or Pause?

## 10. Desk Mat Risk Note

This validation round should not be blocked by Desk Mat cleanup. However, Desk Mat should not be used as a selling claim anchor until the unsupported wool wording is handled.

Current risk locations found in repo:

- Current Shopify title recorded as `Premium Wool Felt Desk Mat`.
- Current handle and URL include `obodesk-premium-wool-felt-desk-mat`.
- Current tags include `material:wool-felt`.
- AI PDP P0 template says `wool felt desk mat` and `Wool felt or felt material - confirm exact composition`.
- Current docs explicitly state wool, natural wool, real wool felt, 100% wool, and wool percentage are not verified.

Risk:

- Existing wording may imply natural wool, real wool felt, or wool percentage without evidence.
- This creates product fact, customer trust, return, and claim-risk issues.

Safe wording draft:

- Safe title: `Premium Felt Desk Mat`.
- Safe material wording: `felt-style surface with dotted backing`.
- Safe summary: `Dark gray felt-style desk mat with dotted backing, 3 mm thickness, and three current size options for keyboard, mouse, laptop, and writing setups.`
- Claims to avoid: wool felt, natural wool, 100% wool, real wool felt, wool percentage, waterproof, water-resistant, stain-resistant, heat-resistant, anti-fatigue, ergonomic benefit, health benefit.

Boundary:

- Do not change Shopify in this round from this draft.
- Keep Desk Mat cleanup as a separate human Shopify Admin task.
- Do not let Desk Mat delay the Monitor Riser first validation cycle.
